Crypto Token Risk Checker

Analyze Base tokens for liquidity, holder concentration, taxes, honeypot signals, and other risk indicators.

API cost: $0.002 USDC per request via x402. This demo page is free; the endpoint itself requires payment.

How It Works

  1. Enter a Base token contract address above.
  2. An AI agent or x402 client calls the paid API.
  3. x402 handles the $0.002 USDC payment automatically.
  4. The API returns the token risk analysis.

The API is designed for agents that need token-risk information before buying, swapping, transferring, or recommending a token.

API

Endpoint GET /api/v1/risk-score
Parameter tokenAddress — required Base token contract address
Price $0.002 USDC per request via x402

Example

GET /api/v1/risk-score?tokenAddress=TOKEN_ADDRESS

Notes

Normal browser requests receive HTTP 402 because payment is required. Use an x402 client or agent to complete the payment flow.
